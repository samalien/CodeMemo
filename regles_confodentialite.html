Politique de confidentialité – CodeMemo

Date d’entrée en vigueur : 28 décembre 2025

CodeMemo est une application gratuite conçue pour aider les étudiants et développeurs à apprendre et réviser les algorithmes avec du code Python exécutable.

1. Données collectées

CodeMemo collecte très peu de données et uniquement lorsque vous choisissez de vous connecter avec votre compte Google :

  • Votre nom d’affichage
  • Votre adresse e-mail
  • Votre photo de profil (si disponible)

Ces informations sont utilisées uniquement pour afficher votre profil dans l’application.

2. Données stockées localement

Vos exercices personnalisés (nom, description, pseudo-code, code Python, exemples) et vos favoris sont stockés uniquement sur votre appareil via une base de données locale.
Aucune de ces données n’est envoyée à un serveur ni partagée avec des tiers.

3. Connexion Google

L’application utilise Google Sign-In pour une connexion rapide et sécurisée. Nous respectons les conditions d’utilisation de Google.
Pour plus d’informations sur la gestion des données par Google : https://policies.google.com/privacy

4. Exécution de code Python

Lorsque vous exécutez du code Python dans l’application, celui-ci est envoyé à un service tiers gratuit (Piston API) uniquement pour l’exécution.
Ce service ne conserve aucune trace de votre code et ne collecte aucune donnée personnelle.

5. Pas de publicité ni de suivi

CodeMemo ne contient aucune publicité et n’utilise aucun outil de suivi (Analytics, etc.).
Aucune donnée n’est vendue ou partagée avec des tiers.

6. Sécurité

Les données locales sont stockées de manière sécurisée sur votre appareil. Aucune donnée sensible n’est collectée.

7. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité. La nouvelle version sera publiée sur cette page.

8. Contact

Pour toute question : samaliplay@gmail.com

Merci d’utiliser CodeMemo ! Cette application a été créée avec passion pour aider les étudiants en informatique à progresser.
